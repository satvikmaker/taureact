# Auto-Updater Setup

TauReact uses Tauri's built-in updater plugin with GitHub Releases.

## 1. Generate a signing key pair

```bash
npx @tauri-apps/cli signer generate -w ~/.tauri/taureact.key
```

This creates:
- `~/.tauri/taureact.key` — private key (keep secret)
- `~/.tauri/taureact.key.pub` — public key (embed in app)

## 2. Configure `tauri.conf.json`

Paste the **public key** into `plugins.updater.pubkey`:

```json
"updater": {
  "pubkey": "dW50cnVzdGVkIGNv...",
  "endpoints": [
    "https://github.com/YOUR_USERNAME/taureact/releases/latest/download/latest.json"
  ]
}
```

Replace `YOUR_USERNAME` with your GitHub username or org.

Then enable updater artifact generation in the same file:

```json
"bundle": {
  "createUpdaterArtifacts": true
}
```

This ships as `false` because Tauri refuses to build once a `pubkey` is set
unless `TAURI_SIGNING_PRIVATE_KEY` is also present — so leaving it on would
break every build until you have completed step 1.

## 3. Set CI secrets

In your GitHub repo → Settings → Secrets → Actions, add:

| Secret | Value |
|---|---|
| `TAURI_SIGNING_PRIVATE_KEY` | Contents of `~/.tauri/taureact.key` |
| `TAURI_SIGNING_PRIVATE_KEY_PASSWORD` | Password you chose during key generation |

These are consumed by `.github/workflows/release.yml`.

## 4. Create a release

```bash
git tag v0.2.0
git push origin v0.2.0
```

The release workflow builds all platforms, signs the bundles, and uploads to a GitHub Release draft. The updater JSON manifest (`latest.json`) is auto-generated by `tauri-action`.

## 5. How it works at runtime

1. 5 seconds after app start, `updater.rs` checks the endpoint
2. If a newer version is found, the UI shows "Update available: vX.Y.Z"
3. The update downloads with a progress bar
4. User clicks "Restart & Update" to install

## macOS notarization

For macOS, add these additional secrets:

| Secret | Value |
|---|---|
| `APPLE_CERTIFICATE` | Base64-encoded `.p12` certificate |
| `APPLE_CERTIFICATE_PASSWORD` | Certificate password |
| `APPLE_SIGNING_IDENTITY` | e.g. `Developer ID Application: Your Name (TEAMID)` |
| `APPLE_ID` | Your Apple ID email |
| `APPLE_ID_PASS` | App-specific password from appleid.apple.com |
| `APPLE_TEAM_ID` | Your 10-character team ID |
